# Vervium CloudAI App

This is the Vervium CloudAI app. Now with 400% more cloud.

## Running the app locally

1. Install Node.js
2. Install app dependencies: `npm install`
3. Run the app: `npm start`
4. Test the app: http://localhost:8080

## Building the app

1. Install Packer
2. Authenticate to AWS
3. Build the AMI: `npm run build`
